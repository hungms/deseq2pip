# Create Pie Chart for ATACseq Annotation

This function creates a pie chart to visualize the annotation
distribution of ATACseq peaks.

## Usage

``` r
plot_pie_chart(annots, comparison, subtitle = "")
```

## Arguments

- annots:

  A vector of peak annotations

- comparison:

  Comparison name

- subtitle:

  Subtitle for the plot

## Value

A ggplot object showing the pie chart
